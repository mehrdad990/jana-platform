# JANA / Kaavosh Architecture
Runtime is UI-independent. Web, future desktop and CLI share the same runtime contracts.
Loop: Understand → Plan → Act → Observe → Verify → Correct → Continue.
Kaavosh: normalize request → multilingual queries → search → extract → validate → normalize price/MOQ → compare evidence → approval-gated outreach → persist run/events → report.
Provider independence is enforced with ModelGateway and ResearchTool interfaces.
